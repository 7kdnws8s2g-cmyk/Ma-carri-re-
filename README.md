# Ma carrière ⚽

Application de suivi de carrière pour jeune footballeur : matchs, buts, statistiques, compétitions, entraînement.

**Site :** https://7kdnws8s2g-cmyk.github.io/Ma-carri-re-/

## L'installer sur son téléphone
- **iPhone (Safari)** : ouvrir le site, toucher Partager ⬆️ puis « Sur l'écran d'accueil ».
- **Android (Chrome)** : toucher « Installer » dans le bandeau, ou menu ⋮ › « Installer l'application ».

Une fois installée, l'appli s'ouvre en plein écran et marche aussi sans internet.

Les données restent sur le téléphone de chaque personne (rien n'est envoyé ailleurs). Pense à faire un export de temps en temps (Profil › Sauvegarde).
